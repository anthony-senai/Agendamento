# Sistema de Agendamento para Barbearia

Barbearia Navalha de Ouro

Sistema web simples para agendamento de horários em barbearias, sem exigir cadastro do cliente.

---

## Sobre o projeto

O projeto resolve o problema da marcação manual (caderno ou WhatsApp), que gera conflitos de horário e retrabalho. O cliente escolhe o serviço, marca um horário disponível e cria uma senha de 6 dígitos para consultar ou cancelar o agendamento depois, sem precisar criar conta.

---

## Objetivo

- Organizar os horários da barbearia
- Evitar conflitos de agendamento
- Não exigir cadastro do cliente
- Permitir consulta e cancelamento via senha de 6 dígitos

---

## Funcionalidades

- Listagem de serviços e preços
- Agendamento sem cadastro (nome + senha de 6 dígitos)
- Validação de data (não aceita data no passado)
- Bloqueio de horários já ocupados
- Consulta de agendamentos por nome + senha
- Cancelamento seguro de agendamento
- Agenda geral para o barbeiro
- Layout responsivo (celular e desktop)
